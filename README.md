# AI-OS V1.0

Status:
AI-OS V1.0 RC1


## Overview

AI-OS is a personal AI Agent Operating System.


## Core Capabilities

- Understand user requests
- Execute tasks
- Connect devices
- Manage runtime state
- Sync offline events
- Store memory


## Architecture

User

↓

Mobile Gateway

↓

AIOS Core

↓

Orchestrator

↓

Runtime Router

↓

Local Runtime / Cloud Runtime

↓

Device Gateway

↓

Sync

↓

Memory


## Supported Devices

- iPhone
- Mac
- XPeng P7

Health Check:

python3 health_check.py

## Core Design


### 1. Brain Interface

Keep unchanged.

Responsibility:

- Receive request
- Normalize context
- Return understanding result


### 2. LLM Gateway

New component.

Responsibility:

- Model connection abstraction
- Provider switching
- Request management


Supported:

- Cloud LLM
- Local LLM


### 3. Rule Engine

Keep existing capability.

Responsibility:

- Fast tasks
- Offline fallback
- Safety fallback


## Decision Flow

## Safety Boundary


LLM cannot directly:

- Control devices
- Execute commands
- Modify system state


All actions must pass:

Brain

↓

Planner

↓

Security

↓

Execution


## Development Scope


Allowed:

- Add LLM Gateway
- Add Model Adapter
- Upgrade Brain reasoning


Not allowed:

- Modify Mobile Gateway
- Replace Execution Engine
- Add unrelated tools


## Verification Criteria


Must pass:

- Existing V1.1 tests
- Brain Interface tests
- Mobile Bridge tests


New verification:

- LLM response parsing
- Rule fallback
- Model unavailable fallback

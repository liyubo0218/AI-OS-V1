# Workflow Engine Architecture Specification


## Status

ARCHITECTURE REVIEW


## Purpose

Manage execution workflow
generated from Planner.


## Position


Brain

↓

Planner

↓

Workflow Engine

↓

Agent Executor



## Responsibilities


Workflow Engine can:

- Load plans
- Manage workflow steps
- Track execution state
- Store workflow status


Workflow Engine cannot:

- Create user goals
- Replace Planner
- Execute commands
- Control devices


## Core Interface


load_plan(plan)


start_workflow(plan_id)


update_step(
 step_id,
 status
)


get_workflow_status(
 plan_id
)

## Security Boundary


Workflow Engine manages process only.

It does not execute actions.

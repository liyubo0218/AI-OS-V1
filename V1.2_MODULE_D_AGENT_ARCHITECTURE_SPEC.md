## Purpose

and system boundary.


## Position

## Agent Responsibility


Agent can:

- Receive execution tasks
- Execute assigned actions
- Track execution state
- Return execution results


Agent cannot:

- Create user goals
- Make high-level decisions
- Replace Brain reasoning
- Modify Memory
- Control devices directly

## Security Boundary


Agent cannot:

- Override Planner decisions
- Skip Workflow
- Access unauthorized devices
- Change system architecture

## Responsibility Boundary


Agent can:


- Receive workflow tasks
- Execute assigned actions
- Return results
- Track execution status



Agent cannot:


- Create goals
- Make decisions
- Modify plans
- Control devices directly
- Replace Workflow Engine
- Replace Brain

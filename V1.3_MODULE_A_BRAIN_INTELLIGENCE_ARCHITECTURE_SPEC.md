## Core Responsibility

Brain Intelligence is responsible for:

- Understanding user intent
- Building goal representation
- Maintaining contextual reasoning
- Providing decision support


## Brain Intelligence Enhancement

### 1. Intent Understanding

Improve:

- User goal recognition
- Context interpretation
- Ambiguous request handling


### 2. Long-Term Reasoning

Support:

- Complex goal analysis
- Multi-step reasoning
- Continuous context understanding


### 3. Context Integration

Combine:

- Memory context
- Current conversation
- Goal state


## Responsibility Boundary

Brain Intelligence can:

- Understand user
- Analyze goals
- Produce reasoning output
- Provide planner input


Brain Intelligence cannot:

- Create workflow
- Execute tasks
- Control devices
- Replace Agent

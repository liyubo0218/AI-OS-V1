## Planner Communication

Brain provides:

- Goal description
- Context information
- Reasoning result


Brain does not:

- Create workflow
- Execute tasks


## Responsibility Boundary

Brain Interface can:

- Receive user input
- Analyze intention
- Build goal representation
- Provide planner input


Brain Interface cannot:

- Execute commands
- Control devices
- Replace Planner
- Replace Agent

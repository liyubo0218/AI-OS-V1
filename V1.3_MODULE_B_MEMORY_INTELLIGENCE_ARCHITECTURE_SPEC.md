## Core Responsibility

Memory Intelligence 2.0 is responsible for:

- Managing long-term user memory
- Evaluating memory importance
- Organizing memory information
- Providing relevant context


## Memory Intelligence Enhancement

### 1. Memory Importance Evaluation

Improve:

- Memory priority scoring
- Important information identification
- Memory retention decisions


### 2. Memory Organization

Support:

- Memory classification
- Memory grouping
- Memory cleanup suggestions


### 3. Context Supply

Provide:

- Relevant user history
- Previous goals
- Useful preferences


## Responsibility Boundary

Memory Intelligence can:

- Store memory information
- Classify memory
- Evaluate importance
- Provide context


Memory Intelligence cannot:

- Decide user intention
- Create workflows
- Execute tasks
- Control devices

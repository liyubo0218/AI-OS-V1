## Importance Evaluation

Memory Intelligence evaluates:

- User preference
- Long-term value
- Task relevance


## Context Provider

Memory provides:

- Relevant history
- User information
- Previous goals


## Responsibility Boundary

Memory Intelligence can:

- Store memory information
- Classify memory
- Evaluate importance
- Provide context


Memory Intelligence cannot:

- Decide user intention
- Create workflow
- Execute tasks
- Control devices


## Integration Boundary

Brain:

Requests memory context


Planner:

Receives context information


Agent:

Does not directly access memory

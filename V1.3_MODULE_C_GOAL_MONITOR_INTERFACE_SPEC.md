## Integration Boundary


Brain:

Provides goal understanding


Planner:

Receives monitoring feedback


Agent:

Provides execution status


Memory:

Stores goal history


## Responsibility Boundary

Goal Monitor can:

- Track goals
- Analyze progress
- Detect deviation
- Generate feedback


Goal Monitor cannot:

- Create goals
- Replace Brain
- Replace Planner
- Execute tasks
- Control devices

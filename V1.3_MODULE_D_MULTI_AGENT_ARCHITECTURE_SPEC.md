## Core Responsibility

Multi-Agent System is responsible for:

- Agent registration
- Agent capability management
- Agent task coordination
- Agent collaboration


## Agent Roles


### 1. Task Agent

Responsible for:

- General task execution
- Workflow actions


### 2. Memory Agent

Responsible for:

- Memory related operations
- Information retrieval


### 3. Device Agent

Responsible for:

- Device interaction requests


### 4. Research Agent

Responsible for:

- Information gathering
- Analysis support

## Responsibility Boundary

Multi-Agent System can:

- Select agents
- Coordinate agents
- Manage execution flow


Multi-Agent System cannot:

- Replace Brain Intelligence
- Replace Planner
- Define user goals
- Directly bypass Gateway security


## Integration Boundary


Brain:

Provides understanding


Planner:

Provides task plan


Agent Manager:

Coordinates execution


Gateway:

Controls external devices


Goal Monitor:

Receives execution status


## Validation

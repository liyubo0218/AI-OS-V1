# Integration Boundary


System Integration Layer:

Can:

- Connect frozen modules
- Transfer structured data
- Validate execution flow


Cannot:

- Replace Brain Intelligence
- Replace Memory Intelligence
- Replace Planner
- Replace Multi-Agent Manager
- Bypass Gateway

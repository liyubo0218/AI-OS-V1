# iPhone Agent Interface Specification

## Purpose

Define communication interface between iPhone Agent and AI-OS Core.

## Position

Application Layer Interface:

iPhone Agent

↓

Application Gateway

↓

AI-OS Core


## Request Interface

iPhone Agent sends:

{
    "request_id": "req_001",
    "input": "帮我准备明天会议",
    "source": "iphone"
}


## Response Interface

AI-OS Core returns:

{
    "request_id": "req_001",
    "status": "completed",
    "result": "任务已完成"
}


## Responsibilities

iPhone Agent can:

- Send user requests
- Receive task status
- Display results


## Boundary

iPhone Agent does not:

- Replace Brain Intelligence
- Replace Memory Intelligence
- Replace Planner
- Replace Task Runtime
- Bypass AI-OS Core


## Development Rule

No implementation before interface approval.

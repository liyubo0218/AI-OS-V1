# Mac Agent Architecture Specification


## Purpose

Mac Agent provides desktop application access for AI-OS.


## Position

Application Layer:

Mac Agent

↓

Application Gateway

↓

AI-OS Core


## Responsibilities

Mac Agent can:

- Receive desktop user requests
- Provide local capability access
- Execute approved actions
- Return execution results


## Boundary

Mac Agent does not:

- Replace Brain Intelligence
- Replace Memory Intelligence
- Replace Planner
- Replace Task Runtime
- Replace Goal Monitor
- Bypass Gateway


## Initial Capability

Version 1:

- File operation interface
- Desktop task execution interface
- Result reporting


## Development Rule

No implementation before architecture approval.

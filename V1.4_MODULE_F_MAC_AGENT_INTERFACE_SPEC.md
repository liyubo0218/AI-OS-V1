# Mac Agent Interface Specification

## Purpose

Define communication interface between Mac Agent and AI-OS Core.

## Position

Application Layer Interface:

Mac Agent

↓

Application Gateway

↓

AI-OS Core


## Request Interface

Mac Agent sends:

{
    "request_id": "mac_req_001",
    "input": "整理桌面文件",
    "source": "mac_agent"
}


## Capability Interface

Mac Agent provides:

{
    "capability": [
        "file_operation",
        "desktop_task_execution"
    ]
}


## Response Interface

AI-OS Core returns:

{
    "request_id": "mac_req_001",
    "status": "completed",
    "result": "文件整理完成"
}


## Responsibilities

Mac Agent can:

- Send desktop requests
- Provide local capabilities
- Execute approved actions
- Return execution results


## Boundary

Mac Agent does not:

- Replace Brain Intelligence
- Replace Memory Intelligence
- Replace Planner
- Replace Task Runtime
- Replace Goal Monitor
- Create independent goals
- Bypass Gateway


## Security

Mac Agent:

- Uses approved permissions
- Does not modify Core logic


## Development Rule

No implementation before interface approval.

# Computer Capability Responsibility


Responsible:


- Provide computer capabilities
- Receive Runtime requests
- Return standardized results


Not Responsible:


- User intention reasoning
- Goal planning
- Core modification


---

# Computer Adapter Responsibility


Responsible:


- Connect computer APIs
- Convert data formats
- Execute approved computer actions
- Return system state


Not Responsible:


- Independent decision making
- Permission bypass
- Runtime replacement
